# Fund Compare Matrix

Fund Compare Matrix is the Phase 1 v11 shortlist layer. It turns the existing Compare checkboxes into a side-by-side research view before the investor moves into X-Ray, Evidence Ledger, Watchlist, or Decision Pack.

## Purpose

Retail investors often compare funds using only past return or brand memory. The matrix broadens that comparison. It shows role, category, risk band, cost, drawdown, consistency, Nadi score, evidence readiness, and a decision question for each fund.

## Current Behavior

The matrix uses the same compare set as Portfolio X-Ray and Decision Pack. When a user checks or unchecks a fund, the matrix updates immediately. The copy action produces a research-only compare note.

Signals shown:

- Shortlist posture.
- Role clarity.
- Duplication risk.
- Cost anchor.
- Evidence anchor.
- Per-fund metrics.
- Per-fund decision question.

## Compliance Posture

The matrix must not crown a personalized winner. It can help users inspect differences, but it should not say one fund is best for the user. Use wording such as shortlist, research, role, cost anchor, evidence readiness, and decision question.

Avoid:

- "This is the right fund for you."
- "Buy this one."
- "Switch from this fund to that fund."
- "Allocate this percentage."
