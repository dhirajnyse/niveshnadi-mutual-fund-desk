# Nadi Briefing Vault

Nadi Briefing Vault is the browser-local memory layer for the Research Briefing. It lets a retail investor save a compact snapshot after reading a briefing, then compare whether the research posture is becoming clearer, weaker, or more action-ready over time.

Each saved snapshot stores the selected fund name, category, risk band, release stamp, briefing focus, audience, depth, priority, briefing score, trust score, action score, evidence score, readiness score, compare count, watchlist count, alert count, review rhythm count, next actions, and pause-flag text. It intentionally stores metadata only. It does not save PAN, folio, CAS, bank data, credentials, account details, contact data, client identifiers, free-form private notes, transaction instructions, personalized advice, approval, or return guarantees.

The vault is useful in Phase 1 because individual investors often research the same fund several times before deciding whether to start, watch, pause, or review. A saved briefing history helps them see whether fresh evidence, stronger trust posture, lower pause flags, or better action discipline has changed the research picture. The copyable vault brief is designed for self review, family discussion, advisor discussion, or future distributor handoff design without crossing into execution or recommendation.

Before launch with live data, the vault should keep source dates and citation paths visible so old or demo-backed briefings never look current by accident. If login, cloud sync, distributor access, or client records are added later, this document must be revisited with consent, retention, deletion, encryption, audit trail, and SEBI compliance responsibilities.
