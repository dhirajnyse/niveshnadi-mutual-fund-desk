# Category Playbook

Category Playbook is the route-selection layer for NiveshNadi. It sits before fund comparison because many retail investors jump directly into scheme names without first deciding which category job they are trying to solve. The feature asks for investor question, time horizon, and risk comfort, then builds category-first research lanes such as core SIP, cash parking, tax-saving, income stability, retirement glide path, growth satellite, or switch review.

The playbook should remain category-led and research-only. It may describe which category lanes to research first and which categories to avoid for a given research question, but it must not crown a single fund as the best choice for the investor. It should never say buy, sell, switch, hold, redeem, execute, or allocate a specific percentage. It can apply a category filter to the demo screener so the investor can continue research in a structured way.

For launch, each category lane should connect to visible source evidence: AMFI category mapping, SID/KIM objective, riskometer band, expense data, portfolio disclosure freshness, benchmark context, and investor-friendly warnings. The playbook note should store release version, inputs, category lanes, guardrails, and avoid-list so the user can attach it to a later decision pack without changing it into advice.

This layer is also useful for monetization because saved category routes, route history, education journeys, and exportable research notes are workflow value, not hidden distribution bias. Nadi Plus can eventually save multiple playbook routes across goals after authentication and privacy controls are designed.
