# NiveshNadi Claim Surface Map

The Claim Surface Map is the Phase 1 trust bridge between Source Receipt Vault and Claim Release Gate. A source receipt can be strong for one area and still unsafe for another, so the map scores each public product surface separately before anything starts to look like live research.

Each surface has a dependency list, a strictness threshold, a release route, a user-facing impact statement, and a fallback. AMFI, AMC factsheet, SID/KIM, portfolio disclosure, benchmark, and TER or riskometer receipts can therefore release only the surfaces they actually support. If a receipt is stale, missing citation visibility, low-confidence, or frozen, the affected surfaces stay in preview or frozen while unrelated surfaces remain usable with clear demo posture.

The first version covers screener cards, fund detail, compare matrix, portfolio X-Ray, dossier, decision pack, review/watchlist, and trust/pricing confidence. It deliberately handles product-surface claims only. It does not require PAN, folio, CAS, bank data, account credentials, contact data, private investor notes, or distributor client records.

Launch use should connect this map to reviewer release receipts, rollback notes, correction notices, and source-date citations. The safest operating rule is narrow freeze: block the exact surface affected by a weak source, explain the status plainly, and keep every public claim tied to a visible source receipt.
