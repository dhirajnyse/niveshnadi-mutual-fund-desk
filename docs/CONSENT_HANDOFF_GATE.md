# Nadi Consent Handoff Gate

The Nadi Consent Handoff Gate is the Phase 1 consent-readiness layer that sits after Share-Safe Export. It answers a simple question before any research pack leaves the investor's own workspace: who is receiving it, what exact scope is allowed, how long the boundary lasts, and which sharing channel is being used.

The gate is intentionally a readiness preview, not a consent database. It does not save consent records, transmit packs, create client profiles, collect PAN, capture contact data, or connect to a distributor workflow. Instead, it creates a copyable consent brief that lists allowed handoff items, blocked data, pre-handoff gaps, recipient boundary, duration discipline, and channel risk.

Blocked items include PAN, folio, CAS, demat, bank, UPI, card, mandate, account credentials, phone, email, address, nominee, family identity, client identifiers, ARN, EUIN, private note bodies, uploaded documents, account statements, transaction instructions, personalized advice, tax advice, approval language, and return guarantees.

For Phase 2, this room becomes the foundation for real consent architecture: explicit consent capture, revocation, retention rules, deletion workflow, audit logging, role-based access, distributor identity, client-data separation, encryption, and regulatory review before any mutual fund distributor or advisor workflow handles personal data.
