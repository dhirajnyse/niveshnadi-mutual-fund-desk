# First 5-Minute Start

First 5-Minute Start is the onboarding layer for NiveshNadi. It gives retail investors a small, sequenced research path before they enter the deeper tools. The aim is to reduce confusion and impulse behavior by turning the first session into five visible moves: profile, lane, shortlist, evidence, and memo.

The progress tracker is stored only in browser local storage. It does not require login, PAN, folio, CAS, bank data, account credentials, or distributor identifiers. The user can reset the tracker at any time. The tracker is a convenience feature and should not be represented as a suitability approval.

## The Five Moves

- Profile: capture need, investor stage, horizon, SIP capacity, risk comfort, emergency buffer, and decision stage.
- Lane: convert the profile into a research workflow route such as first SIP, compare, review, switch, or memo.
- Shortlist: inspect role, cost, risk, overlap, and whether every selected fund has a distinct job.
- Evidence: check source readiness for AMFI, AMC factsheet, SID, KIM, portfolio disclosure, riskometer, and TER.
- Memo: write the reason, amount, review date, evidence status, and compliance boundary before acting.

## Compliance Boundary

This layer is research workflow guidance only. It must not become personalized advice, execution instruction, model portfolio allocation, or a return guarantee. If future versions add accounts, payments, live portfolio import, distributor workspaces, or client management, the security model, data classification, consent language, and SEBI regulatory boundary must be updated before launch.
