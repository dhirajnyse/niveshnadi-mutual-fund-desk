# First SIP Coach

The First SIP Coach turns NiveshNadi from a set of separate research tools into one guided workflow for retail investors. It asks for starting point, years available, risk comfort, monthly SIP budget, and research depth. It then creates a route across category research, fund inspection, overlap discipline, SIP math, and decision journaling.

## Supported routes

- First SIP confidence route.
- Existing SIP review route.
- ELSS tax research route.
- Cash to market STP route.
- Child education goal route.
- Retirement glide route.

## Product behavior

The coach output is deliberately category-led. It can stage demo funds for inspection, move values into the Goal Fit Compass, run the SIP lab, build a sample X-Ray set, and draft a decision journal entry. These actions make the product feel helpful without crossing into personalized fund recommendations.

## Compliance posture

The coach must not say "buy this fund" or "this is best for you." It should use language such as route, research path, inspect, shortlist, guardrail, overlap, and journal. Any future version using live data should cite AMFI, AMC factsheets, SID, KIM, benchmark data, and portfolio source dates.
