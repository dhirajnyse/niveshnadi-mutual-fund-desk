# Smart Navigation Shell

Smart Navigation Shell is the V65 navigation pattern for NiveshNadi. The product now contains many research rooms, so the header cannot behave like a full sitemap. The shell keeps the first row focused on the most repeated tools while the Workspace dropdown remains the complete index for every desk capability.

The visible primary row is intentionally short compared with the full product map: core build, launch, wiring, sandbox, webhook, pilot, vault, pilot gate, tickets, receipt replay, access, data, review, daily, screener, profile, compare, X-Ray, dossier, pricing, strategy, beta, invite, cohort, C-Receipts, Replay, Gate, Ops Room, and Support shortcuts stay visible while the Workspace dropdown remains the complete index. The Webhook shortcut opens the Gateway Decision and Webhook Drill, the Pilot shortcut opens the Payment Provider Pilot Receipt Contract, the Vault shortcut opens the Pilot Receipt Vault in the payment lane and the Account Vault shortcut in the account lane opens V149 account limits and support repair joins, the Pilot Gate shortcut opens the Paid Pilot Launch Gate, the Tickets shortcut opens the Backend Ticket Factory, the Receipt Replay shortcut opens the Receipt Replay Engine, the Access shortcut opens the Entitlement Bridge and its V147 feature access matrix, the Strategy shortcut opens the Market Strategy Room, the Beta shortcut opens the Paid Beta Evidence Pack, the Invite shortcut opens the Founder Invite Proof Path, the Cohort shortcut opens the Founder Cohort Control Room, the C-Receipts shortcut opens the Cohort Receipt Backend, the Replay shortcut opens the Cohort Decision Replay room, the Gate shortcut opens the Paid Cohort Expansion Gate, the Ops Room shortcut opens the Founder Beta Operating Room, the Support shortcut opens the Paid Beta Support Ledger, and a second compact phase rail explains the actual retail workflow in plain order: Profile, Find, Verify, Memo, and Review. This makes the product feel easier to enter without hiding the depth that advanced users need.

## Rules

- Keep the header calm and scannable on desktop.
- Preserve native anchor links for every visible shortcut.
- Keep all deep tools available through the grouped Workspace dropdown.
- Sync active state from scroll, hash changes, and dropdown selection.
- Maintain sticky-header offset behavior so section titles are not covered.
- Do not add user data, account data, PAN, folio, CAS, login, or distributor fields to navigation state.

The shell is a usability layer only. It does not decide suitability, rank funds for a user, execute transactions, or personalize advice.
