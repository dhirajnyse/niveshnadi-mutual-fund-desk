# Research Lanes

Research Lanes is the Phase 1 v34 routing layer for NiveshNadi. It helps a retail investor choose the research path they are actually on before they enter the deeper tools. The lanes are not recommendations. They are workflow routes that decide which checks should be opened first.

## Lanes

- Start first SIP: routes the user toward First SIP Coach, Goal Fit, SIP math, and Decision Pack.
- Compare shortlisted funds: routes the user toward Fund Compare Matrix, Peer Bench, Evidence Ledger, and Portfolio X-Ray.
- Review current portfolio: routes the user toward Portfolio X-Ray, Portfolio Review Room, Review Vault, and Review Rhythm.
- Study switch question: routes the user toward Switch Decision Lab, Cost Lab, Stress Lab, and Decision Pack.
- Prepare decision memo: routes the user toward Research Pulse, Readiness Gate, Decision Pack, and Journal.

## Product Behavior

- Read lane mode, time horizon, amount, selected fund, compare set, evidence readiness, and memo status.
- Produce a compact lane score, posture, primary tool, route tools, and research steps.
- Open the most relevant workspace section without creating advice language.
- Copy a lane note that can be saved with the investor's own research file.

## Compliance Boundary

Research Lanes must never say which fund to buy, sell, switch, redeem, hold, or SIP into. It can only say which research checks are still incomplete and which internal tool should be opened next. Live launch must keep this distinction especially clear when payment, login, portfolio import, PAN, CAS, ARN, EUIN, or distributor workflows are introduced.
