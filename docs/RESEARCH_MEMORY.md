# Nadi Research Memory

Nadi Research Memory is the browser-local timeline layer for NiveshNadi. It brings together saved Research Briefings, Portfolio Review snapshots, Research Receipts, Memory Capsules, Research Dossiers, Investor Records, Claim Release Gate decisions, Watchlist entries, alert metadata, and Decision Journal metadata into one calm research memory map.

The feature is designed for retail investors who may return to the same fund several times before deciding whether to start, increase, pause, switch, or simply keep watching. Instead of forcing the investor to remember which tool was used last, Research Memory shows the latest saved events, coverage gaps, watchlist pressure, alert count, evidence readiness, and next memory moves. It turns the product from a set of research tools into a continuity system.

Research Memory intentionally stores no private identity data. Memory Capsules add only fund ID, fund name, score metadata, route metadata, timestamps, and replay deltas; they avoid PAN, folio, CAS, bank data, contact data, credentials, ARN/EUIN, client identifiers, advice, execution, or private note bodies. The copyable memory brief excludes PAN, folio, CAS, bank data, credentials, account details, contact details, client identifiers, private notes, personalized advice, execution approval, tax guidance, and return guarantees.

V164 Memory Replay compares the current selected fund against the latest saved capsule so the investor can see if signal, evidence, genome, shock readiness, or review hooks changed. This is a research continuity check only; it does not approve, recommend, execute, or rank a fund.
