# Nadi Research Memory

Nadi Research Memory is the browser-local timeline layer for NiveshNadi. It brings together saved Research Briefings, Portfolio Review snapshots, Research Receipts, Research Dossiers, Investor Records, Claim Release Gate decisions, Watchlist entries, alert metadata, and Decision Journal metadata into one calm research memory map.

The feature is designed for retail investors who may return to the same fund several times before deciding whether to start, increase, pause, switch, or simply keep watching. Instead of forcing the investor to remember which tool was used last, Research Memory shows the latest saved events, coverage gaps, watchlist pressure, alert count, evidence readiness, and next memory moves. It turns the product from a set of research tools into a continuity system.

Research Memory intentionally stores no new private data. It reads existing browser-local metadata and avoids copying free-form note bodies. The copyable memory brief excludes PAN, folio, CAS, bank data, credentials, account details, contact details, client identifiers, private notes, personalized advice, execution approval, tax guidance, and return guarantees.

Before cloud sync, distributor access, user accounts, or client management are added, this memory layer must be redesigned with consent, retention, deletion, encryption, access roles, audit logging, and SEBI boundary checks. Until then it remains a local self-research continuity layer only.
