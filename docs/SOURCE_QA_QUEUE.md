# Nadi Source QA Queue

Nadi Source QA Queue is the operational trust layer for Phase 1 live-data preparation. It converts the Data Readiness Room and Citation Binder signals into a ranked queue of source tasks, so the team can see which AMFI, AMC, SID/KIM, portfolio disclosure, benchmark, riskometer, or TER feed needs attention before a claim is allowed to look current.

The queue scores each source by readiness, freshness pressure, citation visibility, extraction confidence, evidence readiness, and owner handoff. It can be filtered for current launch view, dry-run rehearsal, stale-source cleanup, or hard launch blockers, then copied as a compact QA note for release review. Each card explains the next action, blocker count, source age, confidence level, and responsible operating lane.

Privacy guardrails stay strict. The Source QA Queue is about source operations only; it does not require PAN, folio, CAS, account credentials, distributor client identifiers, or private notes. A source can be marked ready only when source date, citation path, extraction confidence, stale-data status, and launch boundary are visible enough for a retail research workflow.
