# Tool Command Palette

The Tool Command Palette is the V251 simplicity layer for the NiveshNadi header. It keeps the full workspace map available, but lets an investor, founder, or reviewer search for any room by plain words such as evidence, pack, pricing, X-Ray, account, source, or review. The palette is intentionally compact: the user presses Find tool, types one term, and opens the matched workspace without scanning the long dropdown.

The palette is built from the same Workspace selector index, so it does not create a second navigation source of truth. Simple View prioritizes the guided five-step research path first, then adds investor record, pricing, and build tracker routes. Full View still exposes every deeper tool through the existing grouped selector. This keeps depth for operators while preserving a calm retail path.

The launch rule is that navigation must make the product feel smaller than its feature count. Any future module should be discoverable by route label, group name, and hash slug, and the palette should never store personal investor data. It is a UI/UX speed layer only.
